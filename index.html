项目简介

这是一组围绕「公开个人信息采集与聚合」的工具代码集合，定位为本地运行、公开数据源、合规红线内的情报收集（OSINT）研究工具。三者共享同一套设计理念，但形态不同，便于在不同场景下取用：

🖥 crawler（Python 桌面爬虫）

Python + tkinter + requests/bs4

输入网址即可把网页正文、标题、链接抓取为 txt。带图形面板与命令行两种入口，可导出原始 HTML、图片清单，支持代理与无头渲染。

📱 apk（Android 爬虫 App）

Java + aapt2/d8/apksigner

把桌面爬虫移植成手机 App：输入链接 → 抓取 → 每个链接单独生成一个 txt。纯 java.* 实现，33KB 自签名 APK，免存储权限。

🔍 osint-desktop（聚合桌面客户端）

Electron + Node + Python

输入片段即聚合画像：手机号归属地、身份证解析、用户名跨站搜索、邮箱注册检测，结果以关系图谱 + 时间线 + 表格呈现并导出报告。

原理说明

1. 网页爬虫（crawler / apk 共用核心逻辑）

两个端的核心都是「取页面 → 解编码 → 抽正文 → 落盘」：

  • 请求层：伪装浏览器 UA，开启 gzip，自动跟随重定向；失败重试 2 次；代理不通自动回退直连，本地地址默认不走代理。
  • 编码识别：优先读 meta charset / HTTP 头；无声明时靠乱码检测回退 GBK，保证中文不乱码。
  • 正文抽取：剔除 script/style/nav/footer 等噪声标签，保留标题层级与列表结构，相对链接补全为绝对地址。
  • 落盘：每个网页独立生成一个 txt，头部带源链接 / 最终链接 / HTTP 状态 / 抓取时间；失败页单独写 _失败.txt 记录原因，互不干扰。

Android 端 Crawler.java 刻意只用 java.* 标准库（HttpURLConnection + 正则解析），因此同一份抓取逻辑能在电脑 JDK 上直接跑回归测试，再编译进 APK；保存走 MediaStore 写公共下载目录，无需申请存储权限。

2. 聚合桌面客户端（osint-desktop）

架构为 Electron 外壳 + 本地后端服务 + 数据源插件层：

Electron GUI ──IPC/HTTP localhost──▶ 本地后端 (Node + Python)
                                    ├─ 输入解析层：识别 手机/身份证/用户名/邮箱
                                    ├─ 聚合引擎：按实体关联成统一画像
                                    └─ 数据源插件层 (Scanner 接口)
                                         phone | idcard | username | email …
  • 手机号：离线用 phonedata 本地库毫秒级查归属地/运营商；在线用搜索引擎 dork 足迹 + 公开 API。
  • 身份证：本地算法——前 6 位地区码表（GB/T 2260）、7–14 位出生日期、17 位加权校验位，无外部依赖。
  • 用户名：Maigret + Sherlock + social-analyzer 多源合并去重，跨上千站点发现账号。
  • 邮箱：holehe 检测 120+ 站点注册情况；GHunt 做 Google 关联（需自备 cookie）。
  • 可视化：关系图谱（实体—关系网）+ 时间线 + 可排序表格，支持 JSON/CSV/PDF/Markdown 报告导出。
合规边界（操作者划线）：数据源白名单排除 .gov.cn / .gov / .mil.cn 等政府、党政军、公检法国安类站点，绝不触碰； 只聚合公开可访问数据，不内置任何需授权密钥才能访问的私密泄露库； 速率控制 / 代理 / UA 随机化由配置项控制，避免把目标站点打挂。

python crawl.py https://example.com
python crawl.py -f urls.txt -o 批量结果.txt
python crawl.py https://example.com --render   # 需 playwright
